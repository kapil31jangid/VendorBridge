# VendorBridge Frontend

React + Vite client for the VendorBridge procurement ERP.

## Setup

```powershell
npm install
npm run dev
```

The client talks to `http://localhost:5000/api` by default. To override it, create a local `.env` file:

```env
VITE_API_URL=http://localhost:5000/api
```

## Build

```powershell
npm run build
```

## Lint

```powershell
npm run lint
```
